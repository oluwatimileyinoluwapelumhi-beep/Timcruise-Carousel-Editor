# Timcruise Carousel Editor

A tool to edit motivational posts downloaded from Instagram by adding your group branding and personal name to boost your social media presence.

## Features

- Add custom text overlays to images
- Insert group name: **THE GROWTH NEXUS [INSIGHT & OUTLOOK]**
- Add personal branding: **@Timilocruise**
- Batch edit multiple images
- Easy-to-use interface

## About THE GROWTH NEXUS

This carousel editor is designed to help grow THE GROWTH NEXUS community by:
- Adding consistent branding to motivational content
- Making posts more personalized and recognizable
- Increasing group visibility on social media platforms

## Getting Started

### Requirements
- Python 3.8+
- Pillow (for image editing)

### Installation

```bash
pip install pillow
```

### Usage

```bash
python carousel_editor.py --image your_image.jpg --group "THE GROWTH NEXUS [INSIGHT & OUTLOOK]" --name "@Timilocruise"
```
