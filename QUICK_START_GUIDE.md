## 💻 **USE ON YOUR COMPUTER (Python Version)**

This is for batch editing multiple images at once.

### Installation (Do this once):

**Step 1:** Open your terminal/command prompt

**Step 2:** Go to your project folder:
```bash
cd Timcruise-Carousel-Editor
```

**Step 3:** Create a virtual environment:
```bash
python -m venv .venv
```

**Step 4:** Activate it:

**Windows:**
```bash
.venv\Scripts\activate
```

**Mac/Linux:**
```bash
source .venv/bin/activate
```

**Step 5:** Install Pillow:
```bash
pip install -r requirements.txt
```

---

### How to Use Python Version:

**Step 1:** Create a folder for your images:
```bash
mkdir input_images
```

**Step 2:** Put your motivational images inside the `input_images` folder

**Step 3:** Run one of these commands:

**For Motivational Posts (Facebook/Instagram):**
```bash
python main.py --mode motivational --input-dir input_images
```

**For Storipod Promos:**
```bash
python main.py --mode storipod --input-dir input_images
```

**For CTA Covers (Calls to Action):**
```bash
python cta_cover_editor.py
```

**Step 4:** Your edited images appear in:
- `edited_posts/` (motivational posts)
- `storipod_edits/` (Storipod promos)
- `cta_covers/` (CTA graphics)
